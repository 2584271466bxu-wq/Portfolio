### H-1B Visa Landscape Dashboard
**Repository:** https://github.com/2584271466bxu-wq/H1B-Landscape  
**Live Demo:** [h1b-landscape.streamlit.app](https://h1b-landscape.streamlit.app/)  
**Status:** Complete

**What it is**
- An interactive Streamlit dashboard that contrasts official H-1B program data (approval rates, geographic spread) with lived experience captured in Reddit r/h1b discussions, surfacing the gap between administrative data and public sentiment.

**What I built**
- Multi-page Streamlit app with choropleth maps, time-series trends, lottery statistics, and VADER sentiment analysis
- Data processing pipelines transforming ~3 GB of DOL LCA disclosure data, USCIS Employer Data Hub records, and Reddit posts into clean, app-ready CSVs
- Custom Okabe-Ito color theme for accessibility-conscious visualization

**Why it matters**
- Combines government data (DOL, USCIS, BLS) with unstructured social media text to reveal discrepancies between policy outcomes and applicant experience
- Demonstrates end-to-end data work: collection, processing, NLP analysis, geospatial visualization, and interactive deployment
- Directly relevant domain knowledge in U.S. immigration and labor market policy
